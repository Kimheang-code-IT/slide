# Solving IT-Related Problems

A self-contained HTML slide deck on structured problem solving for IT issues.

**Live:** https://slide-jade.vercel.app

## Contents

- Why structure matters
- Types of IT problems
- The 5-step process
- Root cause analysis
- Decision making
- Essential tools
- Walkthrough: a website that will not load
- Best practices
- Think before you fix

## Usage

Everything lives in `index.html` — styles and behaviour are inlined. Open it
directly in a browser:

```bash
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

To publish it, deploy the repository as-is to any static host (Vercel, Netlify,
GitHub Pages).
